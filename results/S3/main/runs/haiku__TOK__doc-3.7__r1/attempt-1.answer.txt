```tok
tok 1.0 "Car accident claim handling"

pool insurer "Insurance company"
  lane handler "Claims handler"
    start received "Car accident claim received"
    task search "Search the police report in the police report database"
    task file "Put the police report and the claim documentation in a file"
    task estimate "Calculate an initial claim estimate"
    task plan "Create an action plan"
  lane manager "Claims manager"
    task negotiate "Negotiate a settlement on the claim estimate"
    task inform "Inform the claimant of the outcome"
    end done "Claim handled"

store police "Police Report database"
store checklist "Action Plan Checklist"

reads search police
reads plan checklist

flow received -> search -> file -> estimate -> plan -> negotiate -> inform -> done
```
